04 / THE DATA BENCH

Clean it. Compare it. Keep control.

A small, private workbench for CSV records and JSON values. Preview each edit, keep the original, and take only the changes you choose.

On-device only. No upload, account or saved browser storage. Leaving this tool or reloading clears the session. Download before leaving.

On narrow screens, tables scroll sideways. Keyboard: focus the table and use the arrow keys.
